# Unity and WebGL/Three.js Integration

This folder is intended for your Unity project files. To integrate Unity WebGL builds with your Next.js frontend:

1. Build your Unity project for WebGL and output to this folder.
2. In your Next.js frontend, serve the WebGL build as a static asset or embed it in a page using an iframe or a custom React component.

For Three.js, you can import and use it directly in your Next.js frontend code.
